# Dynoz AI 🚀

[Dynoz AI](https://www.dynoz.ai/) is a modern AI-powered platform focused on delivering intuitive, engaging, and responsive web experiences.  
This repository contains the redesigned frontend implementation with enhanced UI/UX, interactive dashboards, and responsive layouts.

---

## ✨ Features

1. **Redesigned UI/UX**
   - Modern, visually engaging design
   - Intuitive navigation and storytelling-driven layouts

2. **Animations & Motion Effects**
   - Smooth transitions and parallax effects
   - Interactive visual components to boost user engagement

3. **Client-Side Dashboards**
   - Interactive web interfaces for analytics and insights
   - Modular components for scalability

4. **Responsive Layouts**
   - Optimized for desktop, tablet, and mobile devices
   - Adaptive grid and flexible design system

5. **Landing & Product Pages**
   - Dedicated sections for product showcases
   - Dynamic landing pages with motion-driven storytelling

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js
- **Styling:** TailwindCSS  
- **Animations:** Framer Motion, GSAP  
- **Build Tools:** Vite
- **Deployment:** Vercel
